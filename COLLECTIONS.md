# Available Icon Collections

This document lists all **238 icon sets** available in the `@iconify/json` dataset that can be passed to the build script via `--sets=<id1,id2,...>`.

## Quick Presets

```bash
# 1. Modern UI Curated (Recommended)
bun scripts/build-icons.ts --sets=lucide,heroicons,tabler,ri,ph

# 2. Material & Carbon System Icons
bun scripts/build-icons.ts --sets=material-symbols,mdi,ic,carbon

# 3. Brand & Social Logos
bun scripts/build-icons.ts --sets=simple-icons,cib

# 4. Animated Icons
bun scripts/build-icons.ts --sets=line-md

# 5. Build Everything (All 230+ sets)
bun scripts/build-icons.ts --all
```
